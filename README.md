# Israel

Israel is a dark gold Spicetify theme inspired by the Israeli flag.

Features:

- Gold flag stripes and accents
- Star of David background artwork
- Bass-reactive Star of David animation
- Dark panels, buttons and track-list styling
- Gold progress and volume controls

The bass-reactive animation reads Spotify's available waveform metadata and does not change playback or account data.

## Install manually

Copy the theme folder into your Spicetify `Themes` folder, then select the `Israel` theme and run `spicetify apply`.
